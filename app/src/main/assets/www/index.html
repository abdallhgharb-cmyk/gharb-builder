تطبيق تم إنشاؤه محلياً

الفكرة: تطبيق مشاركة سريع التطبيق يحتوي على ثلاث ازرار اساسيه ارسال استقبال ملفات زر الإرسال يعرض خانة الملفات صور فيديو موسيقى تطبيقات يتم التنقل بينهم عبر السحب ثم يتم اختيار الملف عند الإرسال يظهر بروتوكول التصوير قارئ باكورد عبر الكاميرا لمسح زر الاستقبال زر الاستقبال يفتح نافذه كود باكورد يتم تشفير البرتوكولات وتفعيل اذونات التطبيق التخزين والواي فاي والبلوتوث والكاميرا والموقع زر الملفات مزود بمشغل موسيفرظى ومشغل فيديو ومعرض صور لتشغيل الملفات والصور والموسيقى والفيديوهات
