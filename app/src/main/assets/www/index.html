خطوات تحويل التطبيق إلى ملف APK يعمل أوفلاين:

  1. اضغط على زر "تنزيل حزمة التطبيق (index.html)" بالأسفل.
  2. ارفع الملف إلى مستودع مجاني على GitHub Pages أو استخدم أداة Website 2 APK Builder / Cordova / PWABuilder.
  3. التطبيق مزود تلقائياً بـ Service Worker و Manifest لتخزين جميع البيانات والقوانين على ذاكرة الهاتف دون الحاجة للإنترنت.
